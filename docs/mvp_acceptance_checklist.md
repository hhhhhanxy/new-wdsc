# MVP 验收与演示清单

## MVP 目标

面向航空技术 DOCX 文档，实现“模板化生成 + 规则/大模型混合审查 + 报告输出 + 质量闭环”的最小可用平台。

## 演示主线

1. 上传 DOCX 模板到生成模板库，检查章节结构和模板输入字段。
2. 在文档生成页选择模板，填写产品名称、项目名称、关键参数和生成要求。
3. 生成 DOCX 文档并下载查看。
4. 点击“送入审查”，生成文档自动创建审查任务。
5. 在审查页查看进度、问题统计、可信追溯、问题详情和修改建议。
6. 下载 DOCX 审查报告。

## 必备演示材料

- 1 份可用于生成的 DOCX 模板。
- 1 份合格样例文档。
- 1 份包含格式、完整性或一致性问题的样例文档。
- 1 套演示规则集，至少包含规则引擎规则、LLM 规则和规则+LLM规则。
- 1 个“生成后送审”的闭环演示案例。

## 当前版本验收点

| 模块 | 验收点 | 通过标准 |
| --- | --- | --- |
| 文档解析 | DOCX 上传后可解析章节和表格 | 任务正常进入审查流程 |
| 规则管理 | 可查看规则集、启用/禁用规则 | 审查页规则明细同步变化 |
| 混合审查 | 支持规则引擎、LLM、规则+LLM | 结果中可区分问题来源 |
| 可信追溯 | 展示规则集、规则快照、LLM问题数和耗时 | 已完成任务保留本次规则快照 |
| 报告输出 | 可下载 DOCX 审查报告 | 报告包含问题、依据和建议 |
| 模板生成 | 可基于上传模板生成 DOCX | 保留模板结构和主要格式 |
| 生成闭环 | 生成文档可一键送审 | 跳转审查页并创建审查任务 |
| 任务控制 | 支持暂停、继续、停止 | 状态和进度展示清晰 |

## 后续优化优先级

1. 增加问题复核状态的后端持久化：待复核、确认问题、误报、已整改。
2. 支持生成页选择送审规则集，而不是默认全部规则。
3. 增加规则集导出和复制能力，便于不同业务场景复用。
4. 准备标准演示样例包，包含模板、样例文档、规则集和汇报截图。
5. 增强报告版式，突出审查依据、问题分级、整改建议和规则快照。
6. 后续再建设知识库/RAG、多文档一致性和权限审计能力。
